# Clone Task 1: Layout in React

This project recreates the Erased Tapes webpage using React and CSS as part of Web Development II Assessment 1.

The page includes a navigation menu, article sections, image gallery, author information, comments section and footer.

## Technologies Used

- React
- JavaScript
- HTML and CSS
- Vite

## Running the Project

1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.
